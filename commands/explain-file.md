## 任务

读取文件 `$ARGUMENTS` 并用中文进行详细讲解。

## 讲解内容包括：

1. **文件用途** — 这个文件是做什么的，在项目中扮演什么角色
2. **整体结构** — 文件的组织方式（模块、类、函数、配置项等）
3. **关键逻辑** — 核心流程、重要函数/方法的作用，以及它们之间的关系
4. **输入与输出** — 接受什么参数或数据，产生什么结果或副作用
5. **注意事项** — 依赖项、前提条件、潜在问题或值得关注的细节

## 要求

- 全程使用中文回答
- 语言简洁清晰，避免堆砌术语
- 对关键代码片段，注明文件中的行号（格式：`文件名:行号`）
- 如果文件较大，优先讲解最重要的部分
